# Application Access Control Policy, version 4

## AAC-5.1 — Application roles

Application roles must be assigned through an approved access request.

## AAC-5.2 — Dormant access

Application roles unused for ninety days must be reviewed.

## AAC-5.3 — Recertification

Application owners must recertify sensitive roles each quarter.

## AAC-5.4 — Local application rules

An application team may not extend an enterprise identity deadline.
