# Security Incident Procedure, version 5

## SIP-9.1 — Incident containment

The incident commander may request immediate suspension of an identity during an
active security incident.

## SIP-9.2 — Evidence preservation

Security logs must be preserved during an active investigation.

## SIP-9.3 — Separation events

A separation event must be handled under the applicable identity policies.

## SIP-9.4 — Incident scope

This procedure does not create a standing offboarding exception.
