# Device Return Procedure, version 3

## DRP-4.1 — Equipment collection

Company equipment must be requested for return at separation.

## DRP-4.2 — Courier window

A remote worker may retain a device for five calendar days to arrange courier
collection.

## DRP-4.3 — Data wipe

A returned device must be wiped before reassignment.

## DRP-4.4 — Identity separation

Device collection does not authorise continued use of corporate credentials.
