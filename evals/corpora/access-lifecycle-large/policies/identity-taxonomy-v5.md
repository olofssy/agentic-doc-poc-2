# Identity Taxonomy, version 5

## ITX-1.1 — Employment-affiliated security principal

An employment-affiliated security principal is an identity issued to payroll
staff, an agency worker, or a contractor authorised to use a corporate system.

## ITX-1.2 — Workspace credential

A workspace credential is a user credential for a corporate application,
collaboration space, or managed endpoint.

## ITX-1.3 — Elevated entitlement

An elevated entitlement can administer a corporate system or alter its security
configuration.

## ITX-1.4 — Separation event

A verified separation event is the recorded end of employment or an authorised
external engagement.
