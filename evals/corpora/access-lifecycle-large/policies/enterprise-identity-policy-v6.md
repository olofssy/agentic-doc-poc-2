# Enterprise Identity Policy, version 6

## EIP6-3.1 — Separation deactivation

An employment-affiliated security principal should be deactivated by the end of
the final working day after separation.

## EIP6-3.2 — Administrative access

Administrative access should be reviewed at separation.

## EIP6-3.3 — Manual record

Managers should record the date an identity is removed.

## EIP6-3.4 — Historical guidance

This version is retained for historical reference only.
