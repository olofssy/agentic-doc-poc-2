# Remote Working Policy, version 4

## RWP-6.1 — Remote equipment

Remote workers must protect company equipment while working away from an office.

## RWP-6.2 — Connectivity

Remote connectivity must use an approved secure access method.

## RWP-6.3 — Home office closure

Home office arrangements end when employment ends.

## RWP-6.4 — Asset return

Remote workers must follow the Device Return Procedure for equipment return.
