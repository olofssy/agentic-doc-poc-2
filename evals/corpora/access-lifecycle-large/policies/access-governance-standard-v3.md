# Access Governance Standard, version 3

## AGS-2.1 — Scope decisions

Identity scope decisions must use the definitions in the Identity Taxonomy.

## AGS-2.2 — Local obligations

A current local addendum may impose a shorter deadline for a population in its
stated geography when it explicitly identifies the affected access type.

## AGS-2.3 — Procedure hierarchy

A procedure may assign work but may not relax a corporate-policy obligation.

## AGS-2.4 — Exception register

An approved exception must identify the policy obligation it changes and an
expiry time.
