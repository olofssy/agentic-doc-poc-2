# Project Closeout Procedure, version 3

## PCO-4.1 — Project workspace

Project workspaces must have an accountable project owner.

## PCO-4.2 — Handover archive

Project documents may remain available for thirty days after project closure.

## PCO-4.3 — Team membership

Project owners must review team membership at project closure.

## PCO-4.4 — Identity scope

Project closeout does not extend an individual's corporate workspace credential.
