# Sweden Employment Access Addendum, version 3

## SEA-6.1 — Swedish employee workspace credential

For an employee employed in Sweden, an ordinary workspace credential must be
disabled within four hours of the recorded employment end time.

## SEA-6.2 — Applicability

This addendum applies only to payroll employees with Sweden as their employing
location.

## SEA-6.3 — Privileged access

Administrative workspaces remain subject to the immediate deadline in the
Privileged Access Standard.

## SEA-6.4 — Local precedence

This addendum is a current local obligation for the deadline in SEA-6.1.
